# iDrugWG

iDrugWG is the official VPN client from the iDrug team. It helps you stay online using the WireGuard protocol.

## Features
- WireGuard based
- No logs
- Simple to use
- Custom configs and any servers
- Memes inside

## Installation
1. Clone the repository:
   `git clone https://github.com/bykkcs/idrugwg.git`
2. Open in Android Studio.
3. Build the APK:
   `./gradlew assembleDebug`
4. Install on your device.

## Requirements
- Android 5.0+

## Usage
1. Open the app.
2. Import or paste a config.
3. Connect.
